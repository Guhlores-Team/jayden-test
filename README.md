# Directory cleanup: remove businesses from a directory by name

A small tool for a common data-management job: a client sends a list of company names and
asks for those businesses to be removed from a directory. The hard part is that names on the
list rarely match the directory exactly, and a wrong deletion is worse than a missed one.

This is a demonstration project. The directory and the removal list are synthetic
(invented businesses), generated by `make_sample_data.py`.

## How it decides

Every requested name ends up in exactly one group:

| Group | When | What happens |
|---|---|---|
| **Remove** | Name matches once formatting is ignored (`LLC` vs `L.L.C.`, `&` vs `and`, capitals, punctuation), and the city agrees or only one listing has that name | Removed |
| **Needs review** | Likely typo, several listings with the same name, or the city disagrees | Left in place; listed with the candidate listings for the client to approve |
| **Not found** | Nothing similar in the directory | Reported back |

Safety measures:

- Dry run by default. Nothing is removed without `--apply`.
- The original directory is copied to `output/backup/` before any change.
- Every removed listing is written in full to `removal_log.csv`, so a removal can be undone.
- Uncertain matches are only removed after the client signs them off (`--approvals`).

## Result on the sample data

5,000 listings, 600 removal requests containing deliberately messy cases:

| Case | Requests | Correct outcome | Handled correctly |
|---|---|---|---|
| Exact name | 300 | remove | 300 |
| Different formatting | 120 | remove | 120 |
| Same name in two cities, city given | 40 | remove | 40 |
| Same name in two cities, no city given | 30 | review | 30 |
| Name matches but city differs | 25 | review | 25 |
| Typo in name | 60 | review | 60 |
| Not in the directory | 25 | not found | 25 |

460 listings removed, 115 sent for review, 25 not found, and no wrong listing removed.
The matching rules were tuned on this sample, so real data will have cases it scores less
cleanly on; those fall into "needs review" rather than being removed.

## Run it

```bash
python make_sample_data.py
```

```bash
python cleanup.py --directory data/directory.csv --removals data/removal_list.csv
```

```bash
python cleanup.py --directory data/directory.csv --removals data/removal_list.csv --apply
```

```bash
python score.py
```

```bash
python -m pytest -q
```

Requires Python 3.10+ and `openpyxl`.

## Output

- `output/removal_report.xlsx`: summary plus one sheet each for removed, needs review, not found and duplicate requests
- `output/directory_cleaned.csv`: the directory after removals
- `output/removal_log.csv`: full record of every removed listing
- `output/match_results.csv`: every decision, with the reason
- `output/backup/`: untouched copy of the original directory
